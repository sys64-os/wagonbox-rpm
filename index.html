WagonBox RPM Repository

Official DNF/YUM repository for RHEL, Rocky, AlmaLinux, and Fedora.

Quick Setup:

sudo tee /etc/yum.repos.d/wagonbox.repo <<'REPOEOF'
[wagonbox]
name=WagonBox
baseurl=https://sys64-os.github.io/wagonbox-rpm
enabled=1
gpgcheck=1
gpgkey=https://sys64-os.github.io/wagonbox-key/wagonbox.gpg
REPOEOF
sudo dnf makecache && sudo dnf install wagonbox-core wagonbox-ui
